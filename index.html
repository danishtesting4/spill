House rules, briefly

01

No names. Ever.

Emails, phone numbers, @handles and links are stripped automatically before a post is even queued. Names of private individuals aren’t allowed — companies, orgs and public officials are fair game.

02

Receipts over rage

Exposés need something checkable: a document, a public record, a screenshot with the private details removed. “I heard that…” is a rumour, not an expose.

03

A human reads everything

Every drop sits in a review queue first. Approved, rejected with a reason, or sent back — you can check the status of your drop any time with the code you get.

04

No violence, no sexual content involving minors, no targeting private people

Those are removed, not argued with. If you’re in danger, this site is not a hotline — contact local emergency services.

How a static site gets posts live

Two ways out of the browser. Locally: approve it in the moderation desk, hit export wall.json, commit that file — Pages republishes in a minute. Through GitHub Actions: use Send via GitHub in the composer, and a workflow commits it for you once a moderator adds the approve label to the issue. Same rules engine either way, and every published drop gets a code you can look up from any device.

What we keep

Your IP is only ever stored as a one-way hash, used to stop spam and duplicate voting — never to identify you, never shown to anyone, and it isn’t linked to what you wrote in the public feed. No accounts, no email, no cookies for visitors. Your drop code lives in your own browser.
